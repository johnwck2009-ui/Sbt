# SB Sports Quiz

SB Sports Quiz is a simple Khmer-only Telegram bot for answering short sports knowledge questions.

## Features

- Khmer-only interface
- Multiple-choice sports quiz
- Instant answer feedback
- New question button
- No live sports API
- No betting, odds, or predictions

## Setup

Set the Telegram bot token as an environment variable:

TELEGRAM_BOT_TOKEN=your_bot_token

Install dependencies:

pip install -r requirements.txt

Run:

python bot.py
